# Security Policy

## Supported Versions

Only the latest release version of HydrateMe is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.4.x   | :white_check_mark: |
| < 1.4   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in HydrateMe, please do not open a public issue. Instead, report it privately to the maintainer:

- **Email:** karankumarsacher@gmail.com

Please include steps to reproduce, impact assessment, and system information. We aim to acknowledge reports within 48 hours and coordinate a patch release.
